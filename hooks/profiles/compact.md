# Capability Profile: compact

Use the shared core with a small working set. A single-agent approach is the
default; an explicit user selection of SDD (subagent-driven-development)
overrides this default. Preserve the parent workflow and authorization boundary.
This profile changes working depth, not permissions or approval requirements.

Keep one task and its target test evidence in focus. Start from the known path,
retain a short summary of the goal, relevant contract, and next step, and read
only missing excerpts. Avoid repeated full reads or speculative navigation.
Use the smallest implementation that meets the acceptance condition, then run
its focused proof. On a failed or no-op action, diagnose before changing course;
never repeat unchanged parameters. Report unresolved evidence honestly. Once
the deliverable and its required verification are complete, give the truthful
final and stop; do not spend leftover context on extra tools or reviews.
