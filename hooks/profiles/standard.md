# Capability Profile: standard

Use the shared core at ordinary task depth. Preserve the explicitly selected
parent workflow; this profile is not a request for delegation, planning, review,
or fresh approval of already-approved work. Authorization and tool permissions
remain unchanged.

Name the goal, acceptance condition, and relevant contract. Gather targeted
context from known paths before implementing; expand only when evidence exposes
a dependency that changes the decision. Keep one task and its test evidence in
focus, retaining a short summary rather than repeatedly reading full files.
Make the bounded change and run the target tests. Check actual results, distinguish
verified claims from unknowns, and reuse current evidence for an unchanged tree.
Diagnose failed or no-op actions before choosing a different input or approach.
When the agreed finish condition is satisfied, report the result and limits,
then stop. Extra time does not authorize additional review or broader tests.
